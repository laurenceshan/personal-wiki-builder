# Capture Inbox

Place unprocessed notes, Markdown files, images, and source material here. Capture first; classification can wait.

Prefer one note per file and include a timestamp plus enough context to understand it later. A filename such as `YYYY-MM-DD-HHmm--short-topic.md` reduces collisions across devices.

During ingestion, the agent preserves the original under `raw/`, creates or updates source and wiki pages, updates the index and log, and clears processed inbox items according to the canonical schema.

Do not place passwords, tokens, private keys, identity documents, or account credentials here.
