# Pending Core-Change Suggestions

Use this directory when new evidence or discussion would change an established claim, principle, or important decision.

Each suggestion should identify:

- The target page.
- The current content and proposed change.
- The triggering source or discussion.
- The reason for the change and remaining counterevidence.
- The exact decision required from the user.

Apply the change only after the required confirmation. Append human-readable change history to the target page and update `log.md`.
